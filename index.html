1. Matrice de scatterplots

Chaque case compare deux variables avec ses propres graduations. Cliquez sur un point ou faites glisser un rectangle pour sélectionner des individus.

Faites défiler horizontalement pour parcourir les variables ; toutes restent affichées.

Survolez une case pour afficher les deux variables comparées.

2. Coordonnées parallèles

Faites glisser le curseur sur un axe vertical pour choisir une plage de valeurs. Cliquez sur un libellé pour afficher la distribution de cette variable.
